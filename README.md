# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my projects, technical skills, experience, certifications, achievements, and professional journey.

## 🌐 Live Website

**[ankithhegde.com](https://ankithhegde.com)**

---

## 📌 About the Project

This project is a substantial redevelopment of my personal portfolio website, developed during my Web Development Internship at Tech Vedhu.

The website brings together my projects, technical skills, education, experience, certifications, achievements, resume, and contact information into a single responsive and interactive platform.

The main focus of the project was to create a clean and professional user interface with responsive layouts, intuitive navigation, interactive project and certificate sections, and a reliable experience across desktop and mobile devices.

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern and minimal user interface
- Light and dark theme support
- Responsive navigation
- About and education sections
- Experience and professional journey
- Featured project showcase
- Detailed project views
- Certificate showcase and preview

## 📱 Responsive Design

The website was designed and tested across desktop and mobile screen sizes.

Special attention was given to:

- Responsive navigation
- Layout and spacing
- Typography scaling
- Mobile contact form usability
- Certificate preview compatibility
- Touch-friendly interactions
- Consistent presentation across devices

---

## 📜 Certificate Preview

The portfolio includes an interactive certificate viewing system.

Certificate preview images are used to provide reliable rendering across devices, particularly on mobile, while the original certificate PDFs remain available through the open and download options.
